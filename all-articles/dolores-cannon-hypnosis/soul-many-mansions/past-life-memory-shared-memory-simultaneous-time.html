引言：如果并不存在“前世”，催眠回溯看到的是什么？

上一集《人格的多面性》中，朵洛莉丝·侃南的催眠报告提到：所谓“前世记忆”也可能是共享他人的生命记忆。由于你们每一个人都于内在觉知层面彼此相连，所以这些转世记忆得以共享。你们之中任何一人的记忆，也由其他所有人共同拥有。在非常深的层面，你们能够忆起彼此的思想。

而这次报告进一步强调： 并不存在所谓的前世。时间只是物质层面的一个概念。

但如果并不存在“前世”，又该怎么解释催眠回溯中那些具体、清晰的人世经历？为什么有些人会一再进入同一段“前世”？是什么在决定我们接触到哪一段生命经历？如果过去、现在与未来都同时存在，那么回溯一段尚未发生的生命，是否可能？而当未来有多种可能时，又是什么决定我们会进入哪一种未来？是命运？还是自由意志？

这篇报告，正是在回答这些问题。

前世并不存在，而是他人的生命记忆

P：你所谓的前世，其实可以相当准确地称为——某个曾经历过那段生命的人的记忆。

我们会说， 并不存在所谓的前世。 因为从我们的视角看，一切已经发生，一切正在发生，一切都是过去、现在和未来。

由于我们没有时间这一概念，在我们看来，你们每个人都已经成为过彼此，也正在自己的未来成为彼此。我们知道，此刻这对你们来说还不太清楚。不过，在不久的将来，你们每个人都会得到一些信息，届时你们都将面临挑战，被促使去重新审视这个观念——也就是，过去、现在与未来同时存在。

催眠为什么会重复进入同一段前世？

D：令人困惑的正是这点。为什么我们能够一再接触到某一个特定的前世？为什么我每次引导一个人回溯时，不会进入其他不同的生命呢？

P：打个比方，你也可以在整部交响曲中始终追随一个音符。想象一下，你听见某件乐器奏出一个音符，并一路跟随它贯穿整首交响曲；你会看见——更准确地说，是听见——这个音符在乐曲中一次次重现。

你确实可以把这个音符识别为一个独立的身份。同样，只要把视野收窄到你想选择的那个特定区域，你就能在自己的全部历史中，忆起这些所谓的前世。

然而，意识层面的选择看似随机，实际上，你早已为自己预先设定好程序，使自己每次返回时，都会进入那个特定片段。

D：我们能使用“振动”或“能量”这样的词吗？也就是说，那些能够回顾许多前世的人，只是比其他人能够查看更多这样的能量层次，是吗？

P：这样理解是正确的。你们每个人都能回溯更多的能量线索，远超过自己所能理解的范围。虽然这是可能的，但有必要将一个人的经历，限制在那些能够带来当前理解与启发的领域。因此，明智的做法是忽略那些会造成失调的人世经历，因为那并不是原本的目的。

假如你的觉知，在一瞬间接纳所有可供接触的信息，你会不堪重负。因为即使在我们此刻交谈时，在你们每一个看似独立的人格之中，正在发生的事情也远远超过你们所能理解的程度。

「暮雨・注」这也意味着，当回溯到别的生命经历时，并不一定是在进入一个非我的他者，更可能是在接触一个远比当前人格更大的自我结构。

当前人格，只是完整自我的一个面向

P：我们都知道，白色中包含许多不同的颜色，你可以轻易从白色里分离出其中一种。

同样， 你也从自己的高我中，抽出或分离了某种特定能量 ——它是高我的一个组成部分。于是，这股能量被带到你所在的层次，可以说，成为你人格的这一面向。它确实是你自身不可分割的一部分，只是在这个层次获得了自由活动的空间。

此刻坐在这个房间里的你们，只是一座巨大冰山露出水面的尖端。如果你们拥有更多觉知，并能有意识地运用它，就可以把水面之下更多的部分带到当前的层次；反过来也一样，你们分离出来并称为“自我”的部分，也能够前往自身其他能量面向所在的更高层次。

你们中许多人，都会在某个时刻这样做。那并不是在体验另一个人，而是在体验你从未见过的，自身的其他面向。

「暮雨・注」这里有一个很有意思的对应。在颜料或物质色的混合中，颜色往往越混合越暗沉。比如 CMY（青、品红、黄）三种颜色逐渐叠加时，理论上最终会趋近于黑色；而在光的混合中，RGB（红、绿、蓝）三种光叠加在一起，则会被人眼感知为白光。

也就是说，在物质层面，颜色的叠加趋向于暗沉；在光的层面，颜色的叠加却趋向明亮。《生死之间》中提到，物质世界像是精神世界的倒影，两个层面呈现出某种相反关系。这里光与物质色在混合方式上的相反表现，当然不能作为直接证据，但也许可作为一个有趣的象征性线索。

回溯一段尚未发生的生命，是否可能？

D：那么，回顾一段尚未发生的生命，是否可能？

P：没错。你可以前往任何想去的地方：过去、现在、未来，无论是地球上或太空中，都没有区别，任何地点都可以。 （暮雨注：时间也是一种地点， 时间只是用来标记事件的一个坐标） 进入未来起初可能显得困难，只是因为你们不习惯以那种方式思考。所以，是的，你完全可以回溯到一段未来的生命。

D：那应该叫“前溯”。

P：这只是措辞上的问题。

同时性时间：如何理解过去、现在与未来同时存在？

P：正如前面所说，一切都已经发生，同时又什么都没发生。时间的确是一个相对因素。

D：你能否用这个层面的人类容易理解的方式，说明什么是 同时性时间 吗？即过去、现在和未来，同时存在。

P：我们试试看。请想一想直线和圆之间的区别。

如果你画一条直线，并连接这条直线上的两个点，你会发现，连接出来的线段仍然落在原来的直线上，不会形成另一条与它平行的线。但如果是在一个圆内，任意两点之间都可以用一条直线相连（如图）。如果你只把时间当作一个概念，并把它看作一个圆，那么时间中的两个点——无论位于过去、现在，还是未来——都有可能彼此相连。

再假设这个圆变成一条螺旋，两端无限延伸，直到它们实际上成为同一个点。我们借助想象这个螺旋概念，你也许能看出：即便在圆中，也可能存在某种从一端到另一端的线性推进。

「暮雨笔记」关于螺旋的比喻，或许可以这样理解。首先，我们暂时把时间的概念从平面的圆扩展一下视角，想象成一个球状结构，并在此基础上推演 A 和 B 点在球体中的运动路径。

由于我们的灵魂是从源头出发，那么我有理由假设 A 与 B 也是从同一个点出发，然后朝相反两个方向运动：一个“向上”螺旋爬升，一个“向下”螺旋坠落（如图所示）。当然，实际并没有“上下”，准确的说是向外。为方便描述，暂且定义为“上下”。

当它们分别到达某个极限位置，即球体的两极。这时并不会停止运动，可能由于某种吸引力或宇宙法则，它们会折返，继续以螺旋路径向球体的另一极运动。于是，原本向上爬升的 A 开始向下推进，原本向下坠落的 B 开始向上推进。

注意，它们未必是按原路返回。如果你把这个球状结构，想象成一个由一条能量线缠绕而成的线团。可能更容易理解 A 和 B 在这个球形结构中的运动路径，其实可以探索整个球体。最终，它们会再次回到起点，并在那里相遇。

这并不是严谨的几何证明，只是我关于这种时间概念的假想模型。借助这个图景可能更容易理解：时间也许即是一个整体性的结构，而在其中，仍可能存在从一端到另一端的线性推进。或许，对于沿着这条路径移动的我们来说，对时间的感知是线性发展的；而对于更高维度的生命来说，感知到的则是“一切都已存在”的整体结构。

自由意志，产生于物质世界的二元性

P：时间这一观念，本质上属于物质层面，因为物质世界中的一切都必须遵循某些基本概念：有始有终，有生有死，有黑与白，有正与负。必须把这些现实与精神世界区分开来，如此，这些现实就被保留在物质层面，才能实现极化的过程。 二元性观念也由此产生 。正与负，诸如此类。因此，才会有自由意志。而在圆中没有自由意志，因为那里没有开始与结束，也没有黑与白。但在物质层面，你总是存在从一端到另一端的线性进程。

“自由意志”并非是“为了达到目的而不择手段”；它只是现实两极化所产生的副产品。 自由意志之所以演化出来，纯粹是因为物质世界存在两极。 然而，时间并不具有极性。没有所谓“正时间”或“负时间”，只有关于“此刻”与“彼时”的概念。

而就在我们说话时，“此刻”也正在变成“过去”。那么，又怎么会有“现在”呢？时间从不停驻，所以“现在”这个概念自然无法成立。“现在”会于瞬间成为昨天，成为过去。就在你意识到“现在”这个念头时，它就已经过去了。

未来有多种可能，但人生方向决定发生概率

P：所以，没有必要为现在忧虑。只要你愿意，你可以始终都生活在未来。

D：但我听说，我们的未来有很多种可能。

P：是的。不过，根据你人生迄今为止的发展方向，往往可以看出，哪些未来最有可能发生在你身上。此外，自由意志也决定着将要发生的一切。
